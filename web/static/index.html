    How analysis works

    The model first locates the person or area relevant to each check, then classifies that image region. For cashier occupancy, you draw the employee work area. Each finding retains its frame and region for inspection. Video checks use sampled moments, so activity between samples is not assessed.

    Analysis runs on this server using YOLO and MobileNetV3. Temporary uploads are deleted after processing. Findings and saved corrections remain available for export.

    The six checks identify visible conditions. They do not identify employees or count bread items. Before using the observations in a study, assess their accuracy on footage that represents its setting.
